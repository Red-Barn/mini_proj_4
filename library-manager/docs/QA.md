# 양태호 — 스타일링 / QA / 조장

## 구현 범위
- 공통 스타일: src/index.css, src/App.css
- 시안 진입점: src/App.jsx
- 샘플 화면: src/components/LibraryPreview.jsx (서버/API 연결 전)
- 기존 db.json 및 API 설정은 수정하지 않음.
- 목록 검색·정렬·12개 단위 페이지 UI, 상세, 등록·수정, 삭제 확인, 즐겨찾기, 표지 후보 선택을 React 상태로 시연.
- 새로고침하면 샘플로 초기화. 즐겨찾기 localStorage, CRUD API, 실제 AI 후보 생성은 기능 담당자 연결 필요.
- 후보는 CSS 표지 시안이며 이미지 생성 결과가 아님. 스타일·품질 옵션은 연결 전 UI.

## 공통 규칙
- 청록 #246652, 배경 #f7f8f5, 본문 #243c38.
- 기본 글자 16px, 버튼 최소 높이 44px, 표지 비율 2:3.
- 목록 4열 → 3열(900px 이하) → 2열(680px 이하).
- 제목/내용 필수, 저자 선택. 팀 요구사항 변경 시 담당자와 합의.
- 기존 기능 연결 시 시안 안내 문구 제거, 기존 화면을 실제 데이터로 교체.
